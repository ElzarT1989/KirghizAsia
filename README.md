# KirghizAsia — новая версия сайта турфирмы

Кинематографичный лендинг для KirghizAsia (местное франкоязычное турагентство в Кыргызстане, с 2007 года).
Основной язык — французский, также английский и русский (переключатель в шапке; язык определяется автоматически, `?lang=fr|en|ru`).

## Запуск

```
npm start          # http://localhost:3000  (порт берётся из PORT)
```

Зависимостей нет — это статический Node-сервер (`server.js`) с br/gzip-сжатием в памяти.
Файлы кэшируются при старте: после правки перезапустите сервер.

## Структура

- `public/index.html` — разметка (текст по-французски; остальные языки подставляет `main.js`)
- `public/site.css` — дизайн-система и адаптив
- `public/js/i18n.js` — переводы, список туров (`TOURS`), контакты
- `public/js/main.js` — язык, меню, горизонтальная прокрутка активностей, карточки туров и окно тура, форма → WhatsApp
- `public/js/hero.js` — WebGL-слайдшоу героя (растворение с тёплой кромкой, параллакс; без WebGL — обычная картинка)
- `public/js/topo.js` — анимированные горизонтали на фоне блока «Destination»
- `public/img/` — фотографии (взяты с kirghizasia.com)

## Что править

- Туры, цены, сезоны — `TOURS` в `public/js/i18n.js`.
- Телефон / e-mail — `PHONE`, `EMAIL` там же.
- Тексты — `DICT` (fr / en / ru) там же.

## Деплой

Railway подхватывает репозиторий и запускает `npm start` при каждом пуше в `main`.
